7. Integration Techniques

7.1. Integration by Parts

7.1a Learning Objectives

  • I understand how integration by parts compares to the product rule.
  • I understand when and how to use integration by parts.
  • I can choose an appropriate 𝑢 and 𝑣.
  • I can use integration by parts to reduce integrals.

Recall that 𝑢-substitution corresponded to “undoing” the chain rule (when taking derivatives). What corresponds to the product rule?

Product Rule:

dd𝑥[𝑓(𝑥)𝑔(𝑥)]=𝑓(𝑥)𝑔′(𝑥)+𝑓′(𝑥)𝑔(𝑥)

Integrating both sides, and rearranging slightly, we end up with the following

dd𝑥[𝑓(𝑥)𝑔(𝑥)]=𝑓(𝑥)𝑔′(𝑥)+𝑓′(𝑥)𝑔(𝑥)𝑓(𝑥)𝑔(𝑥)+𝐶=∫𝑓(𝑥)𝑔′(𝑥)d𝑥+∫𝑓′(𝑥)𝑔(𝑥)d𝑥𝑓(𝑥)𝑔(𝑥)−∫𝑓′(𝑥)𝑔(𝑥)d𝑥=∫𝑓(𝑥)𝑔′(𝑥)d𝑥

Relabeling the last line with a few substitutions 𝑢=𝑓(𝑥)⇒d𝑢=𝑓′(𝑥)d𝑥 and 𝑣=𝑔(𝑥)⇒d𝑣=𝑔′(𝑥)d𝑥 we end up with

Solution

We don’t know a best method for picking 𝑢 and d𝑣 yet, so let’s try something and see what happens. Let

𝑢=sin(𝑥),d𝑣=𝑥d𝑥,d𝑢=cos(𝑥)d𝑥,𝑣=∫𝑥d𝑥=𝑥22

Then

∫𝑥sin(𝑥)d𝑥=sin(𝑥)𝑥22−∫𝑥22cos(𝑥)d𝑥⏟this integral looks worse

Try the other way around now

𝑢=𝑥,d𝑣=sin(𝑥),d𝑢=d𝑥,𝑣=∫sin(𝑥)=−cos(𝑥)

This gives us

∫𝑥sin(𝑥)d𝑥=−𝑥cos(𝑥)−∫−cos(𝑥)d𝑥⏟which we know=−𝑥cos(𝑥)+sin(𝑥)+𝐶

7.1.1. How to we choose which function to use for 𝑢?

Note

Recall that 𝑢 is a function of which we can easily derive, but not necessarily integrate. We tend to pick things that simplify a lot when we take the derivative of them: logarithms have dd𝑥log(𝑥,𝑏)=1ln(𝑏)𝑥, inverse trig functions have become almost algebraic like dd𝑥arcsin(𝑥)=11−𝑥2, and polynomials which decrease in number of term and power the more you derive them. Alternatively, things that don’t change very much like trig functions and exponential functions might be avoided for 𝑢.

Here is a way to discern potential functions for 𝑢, keeping in mind that you often have to try a few things as you get used to the process.

  1. I: Inverse trig functions
  2. L: logarithmic functions
  3. A: algebraic functions (polynomials, rational functions)
  4. T: trig functions
  5. E: exponential functions

7.1.2. Indefinite Integrals

Solution

If we consider taking the exponential term as our choice for 𝑢, then when we take the derivative of this term, it stays exactly the same. On the other hand, if we let 𝑢=2𝑥 then when we take the derivative we get something simpler. This leads us to want to try 𝑢=2𝑥 first. (But we might have to try something else later)

Then,

𝑢=2𝑥,d𝑣=𝑒𝑥d𝑥,d𝑢=2d𝑥,𝑣=∫𝑒𝑥d𝑥=𝑒𝑥

gives us

∫2𝑥𝑒𝑥d𝑥=2𝑥𝑒𝑥−∫2𝑒𝑥d𝑥=2𝑥𝑒𝑥−2𝑒𝑥+𝐶

Solution

This problem is a little tricky, it needs a substitution first, and then it can be integrated by parts. Let 𝑤=𝑥 then to get d𝑥 we can solve for 𝑥: 𝑤2=𝑥 so 2𝑤d𝑤=d𝑥. Then the integral becomes

∫𝑒𝑥d𝑥=∫2𝑤𝑒𝑤d𝑤

Which we solved in the previous problem. So,

∫𝑒𝑥d𝑥=2𝑥𝑒𝑥−2𝑒𝑥+𝐶
