7.3. Trigonometric Substitutions

7.3a Learning Objectives

  • I can understand the relationship between right triangles and substitutions.
  • I can draw triangles to represent substitutions.
  • I can understand when and how to use trigonometric substitutions.

Suppose we want to derive the formula for area of a circle or radius 𝑟. We know how to set up the integral for this using area between curves:

𝐴=∫−𝑟𝑟𝑟2−𝑥2⏟top−(−𝑟2−𝑥2)⏟bottomd𝑥=2∫−𝑟𝑟𝑟2−𝑥2d𝑥

Up until now, we don’t have a method to evaluate this integral. Looking at a point on the circle we can use trig functions to rewrite the expressions in 𝑥 and 𝑦 into 𝑟 and 𝜃. We have a few options, so let’s do both and compare.

For 𝑥=𝑟sin(𝜃) we get d𝑥=𝑟cos(𝜃)d𝜃. We have to solve little equations for 𝜃 to get our new bounds. Then the integral becomes

𝐴=2∫−𝑟𝑟𝑟2−𝑥2d𝑥=2∫0𝜋𝑟2−(𝑟sin(𝜃))2(𝑟cos(𝜃))d𝜃=2∫0𝜋𝑟2−𝑟2sin2(𝜃)(𝑟cos(𝜃))d𝜃=2∫0𝜋𝑟2(1−sin2(𝜃))(𝑟cos(𝜃))d𝜃=2∫0𝜋𝑟2cos2(𝜃)(𝑟cos(𝜃))d𝜃=2∫0𝜋𝑟|cos(𝜃)|(𝑟cos(𝜃))d𝜃=2∫0𝜋𝑟2cos2(𝜃)d𝜃=2∫0𝜋𝑟2[12(1+cos(2𝜃))]d𝜃=𝑟2∫0𝜋(1+cos(2𝜃))d𝜃

Then we can finish this with a quick 𝑢-substitution, where 𝑢=2𝜃 and d𝑢=2d𝜃 and bounds become 𝑢(0)=0 and 𝑢(𝜋)=2𝜋. Then

𝐴=12𝑟2∫02𝜋1+cos(𝑢)d𝑢=12𝑟2(𝑢+sin(𝑢))02𝜋=12𝑟2(2𝜋+0−0+0)=𝜋𝑟2

And so we can get the area of the circle! You can try doing the other substitution if you want, using the trigonometric identity 12(1−cos(2𝜃))=sin2(𝜃).

Ultimately, either substitution could work if you are careful enough. However, we will just show the substitutions and patterns for the trig subs that don’t give extra minus signs. If you are still confused on why we do things in the order we do them, please come chat in office hours about it! (It honestly took me a while to figure this out myself!)

Here is a “more elegant” way to solve this problem, by which we mean a way that takes a lot fewer steps and uses the triangle a bit more:

We set up the integral the same way, but using trigonometric relations and the triangle reproduced here

We can write

cos(𝜃)=𝑟2−𝑥2𝑟⇒𝑟2−𝑥2=𝑟cos(𝜃)

Combining this with the differential, d𝑥=𝑟cos(𝜃)d𝜃, from before, we can jump straight to

𝐴=2∫−𝑟𝑟𝑟2−𝑥2d𝑥=2∫0𝜋𝑟cos(𝜃)𝑟cos(𝜃)d𝜃=2𝑟2∫0𝜋cos2(𝜃)d𝜃

And from this point we finish the problem similarly to before.
